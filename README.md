# EquiPhysics Education

Free, classroom-ready mathematics labs built on real horse data — no barn required. From [EquiPhysics](https://equiphysics.org), a nonprofit bringing horse lovers to mathematics.

## Labs

| Lab | What it is |
|---|---|
| [`labs/Outreach-HorseGaits`](labs/Outreach-HorseGaits) | **Horse Gait Lab** — a 60-minute hands-on activity on gaits as coupled oscillators: student worksheet, teacher guide, answer key, and slide deck, built around the interactive web app at [equiphysics.github.io/web-apps](https://equiphysics.github.io/web-apps/). |
| [`labs/horse_heart_VdP`](labs/horse_heart_VdP) | **Horse Heartbeats** — model a real equine ECG with the Van der Pol oscillator. |
| [`labs/Gait-1`](labs/Gait-1) | Walk–trot phase models on real sensor data. |
| [`labs/Duque-Exercise`](labs/Duque-Exercise) | Heart rate and heart-rate variability during exercise, on real data. |
| [`analysis_templates`](analysis_templates) · [`Final_Project_Reel_Generator.ipynb`](Final_Project_Reel_Generator.ipynb) | Analysis notebooks for student projects. |

The notebooks run free in [Google Colab](https://colab.research.google.com/) in any browser — nothing to install.
