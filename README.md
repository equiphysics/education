# EquiPhysics Education

Free, classroom-ready mathematics labs built on real horse data. No barn required. From [EquiPhysics](https://equiphysics.org), a nonprofit in Sonoita, Arizona, bringing horse lovers to mathematics. Every dataset here was recorded with our own horses.

Tools and lessons hub: [equiphysics.github.io](https://equiphysics.github.io/). The web apps, the lessons, and the data in one place.

## Labs

| Lab | What it is |
|---|---|
| [`labs/K6-Horses-and-Math`](labs/K6-Horses-and-Math) | **Horses and Math**: a two-hour hands-on lesson for ages 6 to 12: count gait beats with a metronome and hobby horses, then compare kid, horse, and animal heart rates on a printable chart. |
| [`labs/Horse-Heart-Lab`](labs/Horse-Heart-Lab) | **Horse Heart Lab**: a 60-minute activity on the horse's heartbeat: read the ECG (P, QRS, T), measure heart-rate variability, build the beat from a phase clock and five bumps, and compare with Duque's real recordings. Worksheet, teacher guide, answer key, and slides, built around the web app at [equiphysics.github.io/web-apps/heart](https://equiphysics.github.io/web-apps/heart/). |
| [`labs/Horse-Artery-Lab`](labs/Horse-Artery-Lab) | **Horse Artery Lab**: a 75-minute computer lab on blood pressure in a horse, run in [Google Colab](https://colab.research.google.com/github/equiphysics/education/blob/main/labs/Horse-Artery-Lab/Horse_Artery_Lab.ipynb). Stand the horse up and watch gravity, time the pulse down the aorta, stiffen the arteries, and test a published 117-artery model against real measurements. Worksheet, teacher guide with answer key, and a model overview. |
| [`labs/Outreach-HorseGaits`](labs/Outreach-HorseGaits) | **Horse Gait Lab**: a 60-minute hands-on activity on gaits as coupled oscillators: student worksheet, teacher guide, answer key, and slide deck, built around the interactive web app at [equiphysics.github.io/web-apps](https://equiphysics.github.io/web-apps/). |
| [`labs/horse_heart_VdP`](labs/horse_heart_VdP) | **Horse Heartbeats and the Van der Pol Oscillator**: the computational follow-up to the Horse Heart Lab. Model a real equine ECG with the Van der Pol oscillator, a classic equation for self-sustaining rhythms. Includes the strap's own RR intervals from the same ride. |
| [`labs/Gait-1`](labs/Gait-1) | **Walk and Trot from Sensor Data**: turn hoof landing times from motion sensors on Duque into phases and compare a walk and a trot with a coupled-oscillator model of the four legs. Plus 28 more EquiPro stride tables (2024 to 2025) in `data/` for projects. |
| [`labs/Duque-Exercise`](labs/Duque-Exercise) | **Heart Rate and Recovery: Duque's Lunge Test**: heart rate, heart-rate variability, and recovery in one of Duque's weekly lunge tests, with the ECG and accelerometer. |
| [`labs/Horses-and-Music`](labs/Horses-and-Music) | **Horses and Music**: six standing heart-rate recordings of Duque from one day, in silence, with calm music, and with energetic music. Does music change heart rate or HRV? A ready-made student project. |
| [`analysis_templates`](analysis_templates) · [`Final_Project_Reel_Generator.ipynb`](Final_Project_Reel_Generator.ipynb) | Analysis notebooks for student projects, plus scripts for EquiPro stride tables (`equipro/`) and Polar ECG files (`polar/`). |
